Agents that act, inside a fence you set

A permission layer for AI agents

What it does

An agent asks Adeia before it spends money or calls an API. Rules you wrote decide: run it, refuse it, or stop and ask you.

Over the limit

The action stops and a person is emailed. Nothing moves until they approve it.

Off the allowlist

Refused before any request goes out. Hostnames are matched exactly — no wildcards.

On the record

Every outcome lands in an append-only trail with its reason, and a model's verdict is marked as a model's, never as yours.
